As shown in the result we have used Chaning, Linear probing and Quadratic probing. 
Chaning is basically taking modulus of the value, and assign an index which is equal to the reminder. As an example with the value 5.
5%11 = 5. The value 5 is placed in index 5. With chaining, if we get the same index with another value, 
it will put it at the same index but appended as a node in a linked list.

With Linear and Quadratic probing an index can only hold one value. With linear probing if we get the same index we sum it with N so if we get 5,
and the index i occupied: 5+1 = 6, if place 6 is occupied: 5+2 = 7, undtil an empty index is found.

Quadratic probing works similarly, but instead jumps forward in increasing squared
steps: if index 5 is occupied, it tries 5+1^2 = 6, then 5+2^2 = 9 and so on towards N,
and so on, which helps spread out collisions more than linear probing does.

The load factor in Linear and Quadratic probing can maximum become 1, because we cant link it like with chaining, that also means that
the load factor in linear probaing can be bigger than 1.
